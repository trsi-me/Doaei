# منصة دوائي - إدارة الأدوية الإلكترونية

## نظرة عامة
منصة إلكترونية متكاملة لإدارة الأدوية والتذكيرات الطبية باللغة العربية، مصممة لمساعدة المرضى والأطباء والصيادلة في إدارة الأدوية بشكل فعال وآمن.

## الميزات الرئيسية

### 🔐 نظام المستخدمين
- **المرضى** : إدارة أدويتهم الشخصية والتذكيرات
- **الأطباء** : متابعة مرضاهم ومشاركة السجلات الطبية
- **الصيادلة** : تقديم استشارات دوائية متخصصة
- **مقدمو الرعاية** : متابعة أحبائهم من المرضى
- **المديرون** : إدارة المنصة والإحصائيات

### 💊 إدارة الأدوية
- إضافة وتعديل الأدوية مع تفاصيل شاملة
- جدولة الجرعات تلقائياً حسب التكرار المحدد
- تتبع الكميات المتوفرة وتواريخ الانتهاء
- ملاحظات شخصية وطبية لكل دواء

### 🔔 نظام التذكيرات الذكي
- تذكيرات عبر البريد الإلكتروني والرسائل النصية
- إشعارات داخل التطبيق
- جدولة مرنة للأوقات المحددة مسبقاً
- تتبع حالة التناول (تم/لم يتم)

### 📊 التقارير والإحصائيات
- تقارير أسبوعية وشهرية قابلة للتحميل PDF
- إحصائيات معدل الالتزام بالأدوية
- رسوم بيانية توضيحية
- تقارير مفصلة للطبيب

### 🤖 الذكاء الاصطناعي المدرب
- توصيات ذكية مخصصة لكل مستخدم
- تحليل أنماط تناول الأدوية
- اقتراحات لتحسين الالتزام الدوائي
- تنبيهات ذكية للتفاعلات الدوائية المحتملة
- نموذج مدرب باستخدام Random Forest
- تحسين مستمر بناءً على تغذية راجعة من المستخدمين

### 💬 استشارات الصيدلي
- نظام دردشة للاستفسارات الدوائية
- رفع مرفقات (صور الوصفات الطبية)
- إشعارات فورية للصيادلة
- تتبع حالة الاستشارات

### ⭐ تقييمات المنتجات
- تقييم الأدوية من 1-5 نجوم
- تعليقات وتجارب المستخدمين
- نظام فلترة وترتيب المنتجات
- التحقق من صحة التقييمات

### 🔒 الأمان والخصوصية
- تشفير كلمات المرور باستخدام bcrypt
- تشفير البيانات الحساسة
- حماية CSRF وXSS
- سجلات تدقيق شاملة
- سياسة خصوصية واضحة

## التقنيات المستخدمة

### Frontend
- **HTML5** : هيكل الصفحات
- **CSS3** : التصميم والأنماط مع دعم RTL
- **JavaScript (Vanilla)** : التفاعل والوظائف
- **IBM Plex Sans Arabic** : الخط العربي الرئيسي

### Backend
- **Python 3.8+** : لغة البرمجة الأساسية
- **Flask** : إطار عمل الويب
- **SQLAlchemy** : ORM لقاعدة البيانات
- **Flask-Login** : إدارة الجلسات
- **Flask-WTF** : حماية النماذج
- **scikit-learn** : نماذج الذكاء الاصطناعي
- **numpy** : المعالجة الرقمية

### قاعدة البيانات
- **SQLite** : قاعدة البيانات المحلية
- جداول منظمة للمستخدمين والأدوية والتذكيرات
- فهارس محسنة للأداء
- علاقات متقدمة بين الجداول

### الخدمات الخارجية
- **SMS.to** : إرسال الرسائل النصية
- **Mailtrap/Mailgun** : إرسال البريد الإلكتروني
- **ReportLab** : توليد تقارير PDF

## التثبيت والتشغيل

### الخطوات البسيطة (مباشرة)

#### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

#### 2. تهيئة قاعدة البيانات
```bash
python init_db.py
```

**أو لإضافة البيانات الافتراضية إلى قاعدة موجودة:**
```bash
python add_default_data.py
```

#### 3. تشغيل التطبيق
```bash
python app.py
```

#### 4. الوصول للتطبيق
افتح المتصفح وانتقل إلى: `http://localhost:5000`

**ملاحظة:** لا حاجة لإنشاء بيئة افتراضية أو تعقيدات إضافية - فقط الخطوات الأربع أعلاه!

## استكشاف الأخطاء

### مشاكل شائعة

#### خطأ في قاعدة البيانات
```bash
# احذف قاعدة البيانات وأعد إنشاءها
rm doaei.db
python init_db.py
```

#### خطأ في المكتبات
```bash
# أعد تثبيت المكتبات
pip install -r requirements.txt --force-reinstall
```

#### مشكلة في الذكاء الاصطناعي
- عند أول تشغيل، سيتم تدريب نموذج الذكاء الاصطناعي تلقائياً
- النماذج المدربة تُحفظ في مجلد `ai_models/`
- لإعادة تدريب النموذج، احذف محتويات المجلد
